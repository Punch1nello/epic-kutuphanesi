# Epic Kütüphanesi v1.0.0

- Uygulama içi güncelleme adresi yeni GitHub deposuna bağlandı.
- Güncelleme manifesti sürüm numarasını, sürüm notlarını, APK adresini ve SHA-256 doğrulamasını taşır.
- v0.9.0 ile imza sertifikası eşleşmesi doğrulandı; Android mevcut kurulumu güncelleyebilir.
- Mağaza ürün sayfalarında Android geri tuşu WebView geçmişine döner; geçmiş yoksa mağaza ana sayfası açılır.
- Sekmeler arası geçiş sayfaları yenilemez. Aynı kütüphane sekmesine dokunmak verileri yeniler; aynı mağaza sekmesine dokunmak ana sayfayı yeniler veya ürün sayfasındaysa ana mağazaya döner.
- Mağaza, kütüphane, dil, tema ve diğer gezinme iyileştirmeleri korunuyor.
